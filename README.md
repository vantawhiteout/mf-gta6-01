An original open-world crime story in a sun-soaked coastal city: explore on foot or by car, steal vehicles, outrun a five-star police response, shoot your way through a five-mission story and watch the HUD and minimap track it all.

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080` in a desktop browser. `game/index.html` is a static site with no build step and no network requests.

## Play

- **WASD / arrows** — walk, run (Shift) and drive
- **Mouse / left click** — aim and fire your sidearm
- **E** — enter or leave a vehicle
- **Space** — handbrake · **R** — reload · **P** — pause · **C** — continue a saved game

Your progress saves in the browser after each mission.
